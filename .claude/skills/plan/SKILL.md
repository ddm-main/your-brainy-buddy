---
name: plan
description: Plan the day or week — pick 1–3 priorities from projects and areas, timebox if asked. Use when Deepak says "plan my day" or "plan my week".
---

1. Read `Dashboard.md`, all `Projects/*/_overview.md`, and the last few `System/Logs/` entries.
2. Propose 1–3 priorities with a one-line *why* each (deadline, staleness, leverage). If Deepak gave constraints (meetings, energy, hours available), fit around them.
3. On agreement (or if running autonomously, using best judgment): write the plan into today's log, update "Today's Focus" on `Dashboard.md`, and make sure each priority maps to a concrete next action in its project file.
4. For a weekly plan, do the same at week scope and note it in the log as the week's priorities.
