---
name: new-project
description: Start a new project — create its folder, overview file, and dashboard entry. Use when Deepak says "start a project", "new project", or commits to a multi-step outcome.
---

Argument: the project name/idea. Gather (ask only for what's missing and non-obvious): outcome (what does done look like), rough deadline, first next action.

1. Create `Projects/<kebab-name>/_overview.md`:

```markdown
# Project: <Name>

**Outcome:** <what done looks like>
**Deadline:** <date or "none">
**Status:** active · started YYYY-MM-DD

## Next actions
- [ ] <first concrete action>

## Log
- YYYY-MM-DD — project created
```

2. Add the project row to `Dashboard.md`, log it in today's log, and if the project reveals a durable goal, save that to `System/Memory/`.
3. Confirm in one line and state the first next action.
