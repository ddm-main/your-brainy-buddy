name: remember
description: Save a durable fact, preference, or decision to JARVIS memory. Use when Deepak says "remember that..." or corrects how JARVIS works.
---

Argument: the thing to remember.

1. Classify it: profile fact → `profile.md`; working preference → `preferences.md`; person → `people.md`; decision → `decisions.md` (with the why); anything else → a new topical file in `System/Memory/` plus an index line in `MEMORY.md`.
2. Check the target file first — update/correct existing entries rather than appending duplicates. Convert relative dates to absolute.
3. Confirm in one line: what was saved and where.
