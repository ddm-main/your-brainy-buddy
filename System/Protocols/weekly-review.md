# Protocol: Weekly Review

What `/review` walks through (interactive — ask, wait, record):

1. **Clear** — run the `/inbox` flow first if the inbox isn't empty.
2. **Look back** — read this week's logs in `System/Logs/`; summarize wins, misses, patterns.
3. **Projects sweep** — for each project `_overview.md`: still alive? status accurate? has a real next action? Archive dead ones (ask first).
4. **Areas pulse** — one-line health check per area with Deepak; update `_overview.md` files.
5. **Look ahead** — set next week's 1–3 priorities.
6. **Close** — update `Dashboard.md`, write a `System/Logs/YYYY-MM-DD-weekly-review.md` summary, save any new durable facts to memory.
